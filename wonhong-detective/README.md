# 🌍 지구촌 탐정단 – 괴도 원홍을 잡아라!

초등 사회 6학년 (6-1 3단원 · 6-2 1단원) 내용을 활용한 추리 웹게임이에요.

| 파일 | 역할 |
|---|---|
| `index.html` | 게임 본체 (학생용) |
| `config.js` | 구글 시트 연동 주소 설정 |
| `apps-script/Code.gs` | 구글 시트에 기록을 저장하는 코드 |

> **현재 버전은 로그인 없이 바로 4가지 미션 화면으로 시작해요.** 진행 상황·별점·도감은 이 기기(브라우저)에 자동 저장되고, 구글 시트 저장은 사용하지 않아요. 아래 `config.js`·`Code.gs`·1단계는 예전 로그인/시트 방식용으로 남겨 둔 파일이에요.

> `config.js`의 `url`을 비워 두면 **이 기기(브라우저)에만 저장**되는 모드로도 동작해요.

## 1단계. 구글 시트에 학생 기록 저장 (선생님 화면 없이 시트로만 확인)
1. [Google 드라이브](https://drive.google.com)에서 **새 스프레드시트**를 만들어요. (예: `탐정단 기록`)
2. 메뉴 **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 `apps-script/Code.gs` 내용을 통째로 붙여 넣고 저장(💾)해요.
3. 오른쪽 위 **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 권한 승인 → **웹 앱 URL**(`…/exec`로 끝나요)을 복사해요.
4. `config.js`의 `url: ""` 안에 복사한 URL을 붙여 넣어요.
5. 학생이 처음 등록하면 시트에 **`Users` 탭**이 자동으로 생기고, 게임을 할 때마다 학생 한 줄이 갱신돼요.

### 시트에서 보이는 것
학급 · 이름 · 마지막 저장 · 사건별 해결 횟수(황금지구본/자연보석/우리나라/최종) · 별점합 · 도감 · 퀴즈 정답/전체 · **정답률(60% 미만은 붉게)** · 코인 · 진행중(Y) · **취약 단원** · 단원별 정답/시도

- 학급별로 보려면 **데이터 → 필터 만들기** 후 `학급` 열로 필터하세요.
- 비밀번호를 잊은 학생: 열 `C`(숨김)를 **보이기**로 연 뒤 그 학생의 칸을 **비우면** 돼요. 다음 로그인 때 입력한 비밀번호가 새 비밀번호가 돼요.
- 학생 삭제는 그 줄을 지우면 돼요. (`data` 열은 진행 상황 원본이라 건드리지 마세요.)
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영돼요.

## 2단계. 웹으로 서비스하기
게임은 파일 3개짜리 정적 웹사이트라서, 비공개 GitHub 저장소에 두고 **정적 호스팅**으로 열면 돼요.
(자세한 선택지는 대화에서 안내드린 내용을 따라 주세요: GitHub Pages(유료 플랜 필요) / Netlify·Cloudflare Pages(무료, 비공개 저장소 연결 가능))

## 개인정보 안내
- 학생에게 **실명 대신 별명**을 쓰게 하세요.
- 시트의 비밀번호는 암호화(해시)되어 숨김 열에 저장돼요. 그래도 시트는 **선생님 계정에서만** 공유하세요.
- 웹 앱 URL을 아는 사람은 이론상 기록 저장 요청을 보낼 수 있어요. 학급 안에서 쓰는 용도로 설계했어요.
- 학교 정책에 따라 학부모 안내·동의가 필요할 수 있어요.
